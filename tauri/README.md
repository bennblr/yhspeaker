# LA2Speak — десктопный клиент на Tauri 2

Оптимизированная замена Electron-клиенту (`desktop/`): тот же интерфейс и та же
веб-страница сервера, но оболочка на Rust + WebView2. Размер установщика и
потребление памяти заметно ниже, потому что не тащится Chromium.

## Что внутри

| Файл | Назначение |
| --- | --- |
| `src-tauri/src/lib.rs` | вся логика: конфиг, трей, оверлей, горячие клавиши, HTTP-мост |
| `src-tauri/bridge.js` | внедряется в страницу сервера, реализует `window.la2speak` поверх localhost-моста |
| `src-tauri/drag.js` | перенос перетаскивания шапки (`-webkit-app-region: drag`) в вызовы Rust |
| `ui/launcher.html/js` | локальное окно выбора сервера |
| `ui/overlay.html/js` | локальное окно оверлея участников |

Веб-клиент по-прежнему привязан к своему origin, поэтому окно просто открывает
`https://<сервер>` в WebView2. Так как IPC Tauri недоступен для чужих origin,
оболочка поднимает HTTP-сервер на `127.0.0.1` со случайным портом и токеном в
заголовке `x-bridge-token`; `bridge.js` общается с ним long-poll запросами.
Наружу ничего не слушает и без токена ничего не отвечает.

Совместимость с Electron-версией сохранена на уровне веб-клиента: `window.la2speak`
имеет те же методы (`setPttKey`, `setMicMode`, `setMicState`, `setOverlayState`,
`getOverlayConfig`, `setOverlayConfig`, `setOverlayEditMode`, `setBroadcastKeys`,
`onPtt`, `onMicToggle`, `onBroadcastToggle`, `onBroadcastState`, `changeServer`,
`listServers`, `switchServer`, `setServerName`, `getVersion`, `windowControls`).
Поэтому `web/` не пришлось менять под Rust-клиент.

## Требования

- Windows 10/11 x64.
- [Rust](https://rustup.rs) stable (не ниже 1.77.2) с toolchain `stable-x86_64-pc-windows-msvc`.
- Visual Studio Build Tools с нагрузкой «Разработка классических приложений на C++»
  (MSVC и Windows SDK) — нужны линкеру Rust.
- WebView2 Runtime. На Windows 11 уже стоит; на Windows 10 — Evergreen Runtime
  от Microsoft (обычно тоже предустановлен через Edge).
- Node.js 20+ — только для CLI `@tauri-apps/cli`.

## Сборка и запуск

```bash
cd tauri
npm install
npm run dev      # debug-сборка и запуск
npm run build    # release + установщик
```

Установщик: `tauri/src-tauri/target/release/bundle/nsis/LA2Speak_1.0.0_x64-setup.exe`.

Иконки приложения и трея лежат в `src-tauri/icons/`; при замене логотипа
перегенерируйте их (`npm run tauri icon path/to/icon.png`).

## Конфигурация

Файл настроек: `%APPDATA%\ru.la2speak.client\config.json`.
Хранит последний сервер, список посещённых серверов, клавишу PTT, режим
микрофона, включённость/якорь/ручную позицию оверлея, размер шрифта и цвет.
Удаление файла возвращает клиент к первому запуску с лаунчером.

Первый запуск (или отсутствие сохранённого сервера) открывает лаунчер: короткое
имя `chat` превращается в `chat.la2speak.com`, порт можно указать через
двоеточие (`chat:4000`). Кнопка «Сервер» в шапке окна переключает между
посещёнными серверами без перезапуска.

## Горячие клавиши

Глобальные хуки читаются через `rdev` (низкоуровневый хук Windows). Поддержаны
те же токены, что и в веб-клиенте: `A`–`Z`, `0`–`9`, `F1`–`F24`, `Space`,
`Enter`, `Escape`, `Tab`, `Delete`, стрелки, `Numpad0`–`Numpad9`, знаки
препинания, `Control`/`Alt`/`Shift`/`Meta` и кнопки мыши `Mouse3`–`Mouse5`.
Лишние зажатые модификаторы не мешают срабатыванию, отпускание клавиши
сопоставляется без учёта модификаторов.

Если хук не установился (например, его блокирует античит или другое приложение),
`hotkeysAvailable()` вернёт `false`, и клиент покажет предупреждение — кнопки в
интерфейсе и оверлее при этом продолжают работать.

## Трей

Меню: переключение микрофона, показать окно, сменить сервер, выход. Иконка
отражает состояние микрофона и оверлея, подсказка — название канала. Левый
клик по иконке разворачивает главное окно.

## Оверлей

Прозрачное окно поверх всех окон, не в панели задач, не перехватывает мышь в
обычном режиме. Позиция: якорь (по умолчанию справа сверху) или ручная
перетаскиванием в режиме настройки; режим настройки сам закрывается через
2 минуты. Размер шрифта и цвет задаются в настройках веб-клиента.

## Ограничения

- Демонстрация экрана идёт через встроенный выбор источника WebView2
  (`getDisplayMedia`). Отдельный список окон, как в Electron, не реализован.
- Доступ к микрофону запрашивает сам WebView2; при отказе нужно разрешить его
  в параметрах Windows для приложения LA2Speak.
- Установщик не подписан: SmartScreen покажет предупреждение. Для продакшена
  нужен сертификат подписи кода.
- Клиент требует HTTPS-сервер: WebView2 не даёт доступ к микрофону на
  незащищённом origin (кроме `localhost`).
- Код не собирался на машине разработки (нет Rust/MSVC), поэтому первый
  `npm run build` может потребовать правок под версии крейтов.
